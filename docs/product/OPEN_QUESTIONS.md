# Questões abertas

## Valor
- qual evento faz o cliente voltar mensalmente?
- empresário, financeiro ou contador é o usuário primário?
- qual ação concreta o primeiro relatório habilita?

## Caso fiscal mínimo
- qual regime?
- produto ou serviço?
- B2B ou B2C?
- qual ano da transição?
- qual localização?
- quais créditos entram?
- qual fonte oficial sustenta cada transformação?

## Dados
- qual input realmente existe no ERP?
- XML completo estará disponível?
- qual período é necessário: 12 ou 24 meses?
- qual granularidade por SKU é viável?

## Priorização
- o que matematicamente significa "alto impacto"?
- valor absoluto?
- perda de margem?
- percentual?
- combinação?

## Produto
- quais gráficos são realmente úteis?
- que parte fica gratuita?
- qual feature premium é recorrente?
