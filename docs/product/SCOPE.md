# Escopo do MVP

## Objetivo

Provar um fluxo ponta a ponta confiável para um caso tributário pequeno.

## P0 — precisa existir para a demo

- cadastro da empresa;
- perfil mínimo;
- entrada de arquivo/fixture;
- normalização para modelo interno;
- ao menos um cenário fiscal validado;
- cálculo rastreável;
- mapa de impacto;
- um simulador de cenário de negócio;
- gráfico;
- relatório resumido.

## P1 — só entra se P0 estiver estável

- integração com 1 ERP;
- OAuth;
- job de importação;
- histórico ampliado;
- autenticação real;
- persistência completa.

## P2 — depois da validação

- segundo e terceiro ERP;
- chat premium;
- sincronização recorrente;
- mais famílias de regras;
- mais gráficos.

## Não prometer no MVP

- cobertura tributária nacional irrestrita;
- análise jurídica de contrato;
- qualquer empresa/operação;
- IA como autoridade fiscal;
- expansão trabalhista/ambiental como simples reaproveitamento do motor.
