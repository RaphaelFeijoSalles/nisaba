# Nisaba Web

## Instalação

```bash
npm install
npm run dev
```

Depois do primeiro `npm install`, **commitar o `package-lock.json`**.

## Dependências

- React;
- React Router;
- TanStack Query para server state;
- Zod para validar payloads;
- Recharts para gráficos.

Não adicionar state manager global antes de existir necessidade.
